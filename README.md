# Sheet-to-Canvas Universal Master Application

This project provides the universal master prompt and reference React implementation for transforming tabular Google Sheets data into interactive, bi-directionally synchronized Canvas applications.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development environment:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```

## Master Prompt Location
The generic master prompt for Gemini Canvas generation is located in `prompts/UNIVERSAL_MASTER_PROMPT.md`.
