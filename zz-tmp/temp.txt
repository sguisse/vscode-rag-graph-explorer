        <h1>UML Editor Demo</h1>

        <p>
          The UML Editor demo showcases a custom UML node style that renders an UML data set.
          Additional control elements are provided to conveniently add/remove entries and to create
          different type of UML edges as well as toggling the node's 'interface' or 'abstract'
          state.
        </p>

        <p>
          The node style uses an <a href="https://docs.yworks.com/yfileshtml/api/StretchNodeLabelModel" class="api" target="_blank">StretchNodeLabelModel</a> to stack the UML entries on
          top of each other. A custom <a href="https://docs.yworks.com/yfileshtml/api/IEditLabelHelper" class="api" target="_blank">IEditLabelHelper</a> is provided by the UML node
          style to enable editing of the different UML entries.
        </p>

        <h2>Things to Try</h2>
        <ul>
          <li>Click a node to bring up additional control elements.</li>
          <li>
            Create UML specific edges by dragging one of the edge creation controls. A layout will
            route the new edge when the edge creation has finished.
          </li>
          <li>
            Entries can be added/removed with the '+' and '-' buttons on the respective header
            section.
          </li>
          <li>Toggle the node's 'interface' or 'abstract' state with the 'I' or 'A' buttons.</li>
          <li>
            The layout button in the toolbar will create a new layout from scratch and bundle
            inheritance edges.
          </li>
        </ul>
